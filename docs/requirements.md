# 朝型強制（矯正）変換アラームアプリ — 機能要件書

## 1. アプリ概要

| 項目 | 内容 |
|---|---|
| アプリ名（仮） | 朝型強制変換アラーム |
| プラットフォーム | iOS |
| 開発言語 / フレームワーク | Flutter (Dart) |
| フェーズ | MVP（Minimum Viable Product） |

### コンセプト

アラームを設定し、指定時刻にけたたましい音が鳴り始める。ただし、アラームを止めるには**カメラの前で筋トレ（腕立て伏せ or スクワット）を規定回数こなす**必要がある。従来のアラームのように簡単に止められないことで、ユーザーの朝型生活への移行を"強制的に"サポートする。

## 2. 機能要件

### 2.1 アラーム設定機能

- ユーザーがアラーム時刻を設定できる
- アラームの ON / OFF を切り替えられる
- 複数アラームの登録は MVP では不要（1つのアラームのみ）

### 2.2 アラーム発動機能

- 設定時刻になると、けたたましいアラーム音が再生される
- アラーム音はアプリ内蔵の固定サウンドとする（MVP）
- 音量はデバイスの最大音量で再生する

### 2.3 アラーム解除条件（筋トレ検出）

- アラーム解除には、カメラを通じて筋トレの実施を検出する必要がある
- MVP で対応する筋トレ種目は以下の2種類：
  - **スクワット**（10回固定）
  - **腕立て伏せ**（10回固定）
- ユーザーはアラーム設定時にどちらの種目で解除するかを選択する
- 回数はMVPでは固定（将来的にユーザー設定可能にする余地を残す）
- ポーズ推定には `google_mlkit_pose_detection` パッケージを使用する
- カメラはインカメラ（フロントカメラ）を使用する
- 検出中は画面にリアルタイムのカメラプレビューと**残り回数**を表示する
- 規定回数を達成したらアラーム音を停止し、解除完了画面を表示する

### 2.4 自動停止機能（安全装置）

- アラーム発動から **10分** 経過しても解除されない場合、アラーム音を自動停止する
- 自動停止後の挙動は **未定**（MVP初期ビルドではホーム画面に戻る仮実装とする）
- 将来的に「失敗画面表示」「リトライ」等を検討

### 2.5 フォアグラウンド維持方式

- アプリは **フォアグラウンドで動作し続ける** ことを前提とする
- ユーザーフロー：
  1. 就寝前にアラーム時刻を設定する
  2. 「おやすみ」ボタンを押してスリープモードに入る
  3. 画面が暗転し、アプリはフォアグラウンドで待機する
  4. 設定時刻になるとアラーム音が再生される
- スリープモード中は充電を促すメッセージを表示する
- スリープモード中にユーザーが誤ってアプリを閉じた場合の対策は MVP では対応しない（注意書きで対応）

## 3. 画面構成（MVP）

| 画面 | 概要 |
|---|---|
| ホーム画面 | アラーム時刻の設定、筋トレ種目の選択、「おやすみ」ボタン |
| スリープ画面 | 暗転画面。アラーム時刻までのカウントダウン（薄く表示）、充電促進メッセージ |
| アラーム発動画面 | けたたましい音 + 「筋トレを始めてください」の表示 + カメラ起動ボタン |
| 筋トレ検出画面 | カメラプレビュー + 残り回数表示 + ポーズ検出によるリアルタイムカウント |
| 解除完了画面 | 「おはようございます！」等の達成メッセージ |

## 4. 技術構成

### 4.1 使用技術

| 区分 | 技術 |
|---|---|
| フレームワーク | Flutter |
| 言語 | Dart |
| ポーズ推定 | `google_mlkit_pose_detection` |
| カメラ | `camera` パッケージ |
| オーディオ再生 | `audioplayers` または `just_audio` |
| ローカルデータ保存 | `shared_preferences`（アラーム設定の保持） |

### 4.2 ポーズ検出ロジック

- **スクワット検出**: 膝の角度変化（立位 → しゃがみ → 立位）を1回としてカウント
- **腕立て伏せ検出**: 肘の角度変化（伸展 → 屈曲 → 伸展）を1回としてカウント
- 閾値はチューニングが必要（実機テストで調整）

### 4.3 前提条件・制約

- 明るい部屋での使用を前提とする（暗所での精度は保証しない）
- アプリ内で「明るい場所で行ってください」という案内を表示する
- フロントカメラ使用のため、全身が映る距離にスマホを設置する必要がある
  - スマホスタンド等の使用を推奨する旨をアプリ内で案内する

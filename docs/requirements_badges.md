# 達成バッジ機能 — 要件定義

> 統計画面（Premium）内に表示する、連続達成記録に応じたバッジ機能。

---

## 概要

ユーザーが連続でモーニングミッションを達成した日数に応じて、バッジを獲得できる仕組み。
統計画面内にバッジ一覧セクションを設け、達成済み／未達成のバッジを表示する。
ゲーミフィケーション要素により、朝活の継続モチベーションを高めることが目的。

---

## バッジ一覧

| バッジ名（仮） | 獲得条件 | イメージ |
|---|---|---|
| 🌱 めばえ | 連続 3日達成 | 芽が出た段階。スタートの一歩 |
| 🔥 スタートダッシュ | 連続 7日達成 | 1週間継続。習慣の入り口 |
| ⭐ ルーティン | 連続 14日達成 | 2週間。習慣として定着し始め |
| 💎 モーニングマスター | 連続 50日達成 | 本格的な朝型人間 |
| 👑 レジェンド | 連続 100日達成 | 最高ランク。揺るぎない朝型 |

> バッジ名・アイコンはデザインフェーズで確定。上記は仮称。

---

## 表示仕様

### 統計画面内での配置

- 統計画面の中段あたりに **「達成バッジ」セクション** として横スクロールで一覧表示
- 画面の主役はあくまで統計データ（カレンダー、成功率等）であり、バッジはセクションの一つ
- 参考：添付画像（QUITTR）のような画面中央に大きく表示する形式ではなく、あくまでセクション内のコンパクトな表示

### バッジの状態表示

| 状態 | 表示 |
|---|---|
| 未獲得 | グレーアウト + シルエット + 「?日連続で解放」のテキスト |
| 獲得済み | フルカラー表示 + バッジ名 + 獲得日 |
| 最新の獲得バッジ | 軽いハイライト（光彩等）で強調 |

### 獲得時の演出

- バッジ獲得条件を満たした朝のミッション解除完了画面で、バッジ獲得通知を表示
- 簡易的なアニメーション（例：バッジがポップインする演出）
- ここからSNSシェアへ導線をつなげる（既存のSNSシェア機能と連動）

---

## データ設計

`mission_log` テーブル（既存）から連続日数を算出し、バッジ獲得を判定する。
バッジ専用のテーブルは以下。

```sql
CREATE TABLE badges (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  badge_type TEXT NOT NULL UNIQUE,  -- sprout / start_dash / routine / master / legend
  unlocked_at TEXT NOT NULL         -- 獲得日時
);
```
